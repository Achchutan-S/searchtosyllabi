Reputation alone had proved misleading — ocw.mit.edu course-admin pages score 0.95 on domain while carrying no curriculum at all. Highlighted rows were structured.

How the merge reasoned

The consensus across the first three standard data structures courses emphasizes foundational concepts, linear structures, trees, sorting, and graph algorithms. Source 4 represents an advanced graduate-level course on advanced data structures, which was largely filtered out except for persistent data structures and linear-time sorting overlapping with standard curricula. Generic administrative items like exams, syllabus reviews, and introductory fluff were excluded per instructions. Topics were grouped into logical thematic units and ordered pedagogically from basic analysis to complex graph and tree structures.
